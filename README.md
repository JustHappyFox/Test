# Мобильный контролёр

Android-приложение для контролёра Энергосбыта: снятие показаний и управление реле
нагрузки счётчиков Энергомера CE208BY / CE318BY и Миртек через оптоголовку или
радиомодуль, подключённые к телефону по USB OTG.

Сейчас в репозитории **пробник с двумя протоколами**. Он нужен, чтобы на реальном
оборудовании проверить связь и снять первые показания, а по логам доделать рабочий экран.

Что умеет приложение:

- список USB-устройств на OTG с VID/PID, классами интерфейсов и подобранным драйвером
  (FTDI, CP210x, CH34x, PL2303, CDC-ACM), принудительный выбор драйвера;
- **Энергомера CE (IEC 61107 / ГОСТ IEC 61107-2011):** автоподбор скорости и формата
  (9600 7E1, 300 7E1, 9600 8N1, 300 8N1, затем остальные), удачная комбинация запоминается;
  запрос идентификации `/?!`, стандартное считывание показаний, вход по паролю (P1),
  чтение `R1`, запись `W1`, выход `B0`, произвольный текст;
- **МИРТЕК (фирменный протокол, описание v1.20):** Ping, показания по тарифам (0x05),
  дата и время (0x1C), информация о счётчике (0x30, 0x10, заводские строки 0x0A),
  **включение и отключение реле нагрузки (0x3A) с подтверждением**, произвольная команда
  в HEX; порт 9600 8N1, нужен сетевой адрес счётчика и пароль;
- подробный лог обмена с HEX-дампом и кнопка «Отправить лог» (в мессенджер, почту).

## Как проверить в поле

1. Установите `app-debug.apk` на телефон (разрешите установку из неизвестных источников).
2. Подключите оптоголовку (или радиомодуль) через переходник USB-C → USB.
3. Откройте приложение, нажмите **Обновить**. Устройство должно появиться в списке
   с подписью драйвера. Если написано «драйвер не найден», нажмите **Инфо USB**,
   затем **Отправить лог** — по классам интерфейсов будет понятно, какой драйвер нужен.
4. Нажмите **Подключить**, подтвердите разрешение Android.
5. **Энергомера:** протокол «IEC 61107», приложите оптоголовку и нажмите **Опрос /?!**.
   Скорость и формат подбираются сами, найденная комбинация появится в строке состояния.
   Затем **Показания**: в логе будут строки вида `1.8.0 = 05801.969 kWh`.
6. **Миртек:** протокол «МИРТЕК», введите адрес счётчика (как в MeterTools) и пароль,
   нажмите **Ping**, затем **Показания** и **Инфо счётчика**.
7. Отправьте лог целиком — он нужен для следующего этапа.

Реле у Миртека управляется командой 0x3A из описания протокола, с диалогом подтверждения.
Первое отключение делайте на стендовом счётчике. Несколько подряд неверных паролей
блокируют интерфейс счётчика до конца суток, поэтому пароль вводите внимательно.

## Сборка

**Android Studio.** Откройте корень репозитория как проект Gradle (AGP 8.5, compileSdk 34,
minSdk 24). Приложение написано на Java без AndroidX, библиотека USB-serial лежит в модуле
`usbserial`. Сборка в Android Studio из этой среды не проверялась (нет доступа к репозиторию
Google), поэтому при первом открытии возможны мелкие правки в `build.gradle`.

**Без Android Studio** (так собран приложенный APK), на Ubuntu 24.04:

```bash
sudo apt install aapt apksigner zipalign dalvik-exchange
mkdir -p /opt/android-tools && cd /opt/android-tools
curl -o android-all-34.jar https://repo1.maven.org/maven2/org/robolectric/android-all/14-robolectric-10818077/android-all-14-robolectric-10818077.jar
keytool -genkeypair -keystore debug.keystore -storepass android -keypass android \
  -alias androiddebugkey -dname "CN=Android Debug,O=Android,C=US" -keyalg RSA -validity 10000
cd <репозиторий> && tools/build-apk.sh      # -> build/manual/app-debug.apk
tools/run-selftest.sh                       # проверка протокольного слоя на ПК
```

Из-за дексера `dx` код пишется в стиле Java 8 без лямбд и ссылок на методы.

## Структура

```
app/src/main/java/by/mobilemeter/
  MainActivity.java              экран пробника
  transport/SerialLink.java      интерфейс канала (USB сейчас, радио позже)
  transport/UsbSerialLink.java   канал через usb-serial-for-android
  transport/UsbDevices.java      перечисление и описание USB-устройств
  protocol/iec62056/             сессия IEC 62056-21 / ГОСТ IEC 61107, разбор ответов
  protocol/mirtek/               кадр, CRC8, байтстаффинг и команды протокола МИРТЕК
  util/                          лог, HEX
app/src/test/java/...           сценарные тесты с «поддельными» счётчиками (IEC и МИРТЕК)
usbserial/                       копия usb-serial-for-android 3.8.1 (MIT)
tools/build-apk.sh               сборка APK без Android Studio
docs/обследование.md             что известно о счётчиках и что ещё нужно выяснить
```
