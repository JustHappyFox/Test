# Журнал требований: «Меню программ»

Маленькая отдельная программа: одно окно (один ярлык на рабочем столе), из которого запускаются «Поиск абонента»,
«Оформление договора» и «Фото с телефона». Файлы: `menu.ps1` (скрипт со встроенным C#), `zapusk.vbs`, `zapusk.bat`,
`instrukciya.txt`. Архив для пользователя - `menu.zip` (корень репозитория); в общем архиве всех программ - папка `menu`.

## Постоянные правила проекта
- Меню только запускает программы из их папок (их zapusk.vbs). Ничего в папках программ не пишет, файлы не переносит.
- Свои настройки (где какая программа) - nastroiki.txt в папке меню.

## Журнал (дата - требование - статус)
- 10.11 - Пользователь спросил, что ещё сделать «для автономной оптимизации работы». Предложено 9 пунктов: (1) резервная
  копия папок документов, (2) проверки перед сохранением (поверка, пломба не из партии / в двух документах, контрольная цифра,
  пустые поля), (3) автообновление программ из общей сетевой папки, (4) остаток партии пломб и отчёт пломб в конце месяца,
  (5) напоминание о невернувшихся справках, (6) контроль выполнения своих нарядов по базе, (7) пакетный перевод из юр в физ,
  (8) отчёт за месяц (количества), (9) одно меню для трёх программ. Ответ: «Из всего только 9 норм, остальное нахуй» -
  пункты 1-8 ОТВЕРГНУТЫ, не предлагать снова без просьбы. Делаем 9 - одно меню (один ярлык), из которого открываются
  «Поиск», «Договор» и «Фото». - сделано 10.11: папка `menu` (menu.ps1, zapusk.vbs/bat, instrukciya.txt). Окно «Программы»
  (тёмное, как «Договор»): три плитки - номер, название, что умеет, какая папка взята; щелчок или 1/2/3 - запуск программы её
  zapusk.vbs (нет его - скрипт через PowerShell без окна), Esc - закрыть; галочка «Закрывать меню после запуска» (по умолчанию
  вкл., запоминается). Папки программ - сами: папка меню, соседние, на ступень выше, рабочий стол, «Документы», диски (две
  ступени); из нескольких копий - та, где программой уже работали (рабочие файлы: у «Поиска» poisk.txt / indeks_fio.dat, у
  «Договора» nastroiki.txt / «Договоры» / «Справки», у «Фото» nastroiki.txt / telefony.txt), а не свежераспакованная; запоминаются
  в nastroiki.txt меню; «папка…» у программы - выбрать вручную (проверяется, что там её скрипт), «Искать программы заново».
  «Создать ярлык «Программы» на рабочем столе» - ярлык на zapusk.vbs меню со своим значком (menu.ico рисуется сам: синий
  квадрат с тремя полосками цветов программ). Проверено под Xvfb на имитации папок: рабочая копия «Поиска» выбрана вместо
  свежей, запуск по щелчку и клавишам, не та папка - отказ, меню закрывается/остаётся по галочке, значок. Ярлык (WScript.Shell)
  здесь не проверить - на Windows проверит пользователь.
