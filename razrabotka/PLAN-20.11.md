## 3. Как устроен «Договор» (что переиспользовать для БС)
- DocxTemplate (стр. ~271): поля шаблона «ИМЯ» (текст), «□ИМЯ» (флажок), «¶ИМЯ» (абзац убирается, если пусто; в ячейке
  таблицы «¶» убирает ВСЮ строку таблицы), ExpandRows (строки таблицы по строке-образцу - для нескольких ПУ/линий),
  DropPara, TwoCopies, вставка картинки (QR справки - SpravkaQr) -> для схемы в «потерях».
- Своя Zip (ZipEntry/Crc32/Zip, стр. ~157-270): читает/пишет zip без .NET 4.5 -> годится и для чтения xlsx.
- Lists (spravochniki.txt): выпадающие списки, «свое», дописывание новых разделов в файл пользователя с меткой.
- RequiredDialog: обязательные поля по галочкам (ОбязательныеПоля в nastroiki.txt).
- «Текст справки»: галочки строк (запоминаются) - так же для строк БС (строка «минусуются», и т.п.).
- Seals (ВА, КК, «другие» с местом) + SealRegistry (стр. ~24994): пломбы собираются из папок данных договоров и справок
  (Read(dataDir): plomba_vvod, plomba_klemm, plomba_drugoe; ls, data, pu1_zav, adres) -> для БС добавить третий источник
  (папка данных БС; в столбце «№ договора / лицевой» - номер договора юр лица, адрес - адрес объекта).
  PlombyForm, SealBatch, SealPrint - партии, отчёт, печать - уже есть.
- Журналы (SpravkaLogForm, DogovorLogForm) - можно сделать «Журнал БС».
- Меню StartMenu: плитки (сейчас 6 плиток, влезает в 1366x768 впритык) - БС нужна новая плитка.
- Сохранение: документ Word + «данные/<имя>.txt» (ключ=значение), «Открыть сохранённый…», автосохранение, Предпросмотр.

## 5. Как сделать источник «Excel» (предложение)
- Движок обоих программ завязан на DbfTable (SearchResult.Table/Rows - номера записей DBF, индексы IndexReader по CDX).
  Предложение: класс ExcelTable с тем же «лицом», что нужно поиску (поля по именам DBF через таблицу соответствия, записи по
  номеру строки) + свои индексы в памяти (лицевой, счётчик, адрес н.п.+улица+дом+корп+кв, ФИО) - строятся при чтении файла.
  Поиск/карточка/поиск по списку/Excel-выгрузка/сельсоветы работают поверх него без переделки логики.
- Читать файл при запуске/смене пути; файл изменился (дата/размер) - перечитать. В окне - «данные из выгрузки от <дата файла>»
  (выгрузка не живая - старые данные видно). Противоречит старому запрету «не грузить всю базу в память» - тот запрет про живую
  DBF; для выгрузки иначе нельзя (индексов нет) -> подтвердить у пользователя (вопрос 3).
- Общие настройки источников - ОДИН файл, который пишет меню и читают Поиск и Договор (например nastroiki-dannyh.txt рядом
  с папкой меню или в профиле): Источник=база|excel, Быт=путь.xlsx, Юр=путь.xlsx, Наряды=путь.xlsx. Меню: кнопка «Настройки…»
  (3 пути, «Выбрать…», выбор источника, проверка файла - сколько строк, какие столбцы узнаны). Нет меню - программы берут
  прежние пути (обратная совместимость).
- Договор в Excel-режиме: лицевой -> Ф.И.О., тел., адрес, счётчик (как сейчас из базы), проверка копии лицевого по выгрузке
  (+ предупреждение, что выгрузка от <даты>), книга лицевых соседей. Перевод из юр в физ в Excel-режиме - скрыть.
