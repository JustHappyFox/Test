## Сборка и проверка (поставлено 20.11)
Инструменты (копия в `razrabotka/tools/` этого репозитория и в scratchpad `tools/`):
- `apt install mono-complete libgdiplus dotnet-sdk-8.0` (mcs, Mono WinForms, Roslyn csc.dll в /usr/lib/dotnet/sdk/8.0.134/Roslyn/bincore).
- Справочные сборки .NET 2.0: `git clone --depth 1 --filter=blob:none --sparse https://github.com/mono/reference-assemblies.git ra`,
  `git sparse-checkout set v2.0 v3.5` -> scratchpad `refasm/ra/v2.0`.
- `razrabotka/tools/check.sh <программа.ps1>...` (пути внутри - к scratchpad, при новой сессии поправить) - вынимает C# между `$code = @'` и `'@` и проверяет: Roslyn .NET 2.0 + C# 2 (ISO-2,
  warn:4), Roslyn .NET 4.5, mcs ISO-2, и `?:` с двусторонним приведением (byte/int) - своя проверка на Roslyn
  (`tools/ternary`, собрать: `dotnet build -c Release -o out`). Ловит известную ошибку Windows 7 (проверено).
  20.11 все 4 программы: 0 / 0 / 0 / 0.
- `razrabotka/tools/run.sh <menu|foto|prosmotr|dogovor> <папка программы> <сек> <png>` - запуск под Mono в Xvfb :77 + скриншот
  (сначала check.sh - он собирает *_mono.dll); путь run.sh/check.sh к программам - /home/user/Test/<папка>. Меню и Договор 20.11 запускаются.
- ПРАВКА ФАЙЛОВ: .ps1/.txt программ - UTF-8 с BOM и CRLF. Python в текстовом режиме теряет CRLF (20.11 так и вышло - весь файл
  в diff). Править через `razrabotka/tools/pyedit.py` (Doc(path).rep(old,new).save()) или инструментом Edit; после - `file x | grep CRLF`.
- `razrabotka/tools/runtest.sh <prog> <тест.cs> <папка> <png-префикс> <сек...>` - сценарий-проверка (C#, поля через отражение),
