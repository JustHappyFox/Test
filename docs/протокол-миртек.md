# Протокол МИРТЕК: что используется в приложении

Источник: «Описание протокола», версия документа 1.20, Ставрополь, 2015 (старое,
переходное и новое поколение счётчиков). Сам документ в репозиторий не кладём.

## Кадр

```
73 55 | Parameters | 00 | AddrDst (2, мл. байт первым) | AddrSrc (2) = FF FF | Cmd | Password/Status (4) | Data (0…31) | CRC8 | 55
```

- Parameters: бит 7 C (данные закодированы, у нас 0), бит 6 V0 (0 — счётчик),
  бит 5 D (1 — запрос, 0 — ответ), биты 4…0 — длина поля Data.
- Адрес 0xFFFF — широковещательный, ответа не будет. Адрес программы опроса 0xFFFF.
- Пароль 4 байта в запросе; в ответе на этом месте статус: роль, два информационных байта
  (пломбы, магнит, реле: бит 1 — есть реле, бит 2 — тип, бит 3 — нагрузка отключена),
  код ошибки (0x00 OK, 0x01 неверный пароль при записи, 0x04 неверная длина, 0x05 интерфейс
  заблокирован, 0x07 неверный пароль при чтении, 0x08/0x09 невозможно выполнить, 0x0A уже выполнено).
- CRC8: полином 0xA9, стартовое значение 0, считается по байтам между стартом и CRC.
- Байтстаффинг между стартом и стопом: 0x55 → 0x73 0x11, 0x73 → 0x73 0x22.
- Многобайтовые числа — младшим байтом вперёд. Энергия хранится целым числом, положение
  запятой задаёт конфигурационный байт (биты 1,0: 0…3 знака после запятой; биты 7,6:
  число задействованных тарифов).
- Порт: 9600, 8N1 на любом интерфейсе.

## Команды, которые использует приложение

| Код | Имя | Данные запроса | Ответ |
|---|---|---|---|
| 0x01 | Ping | — | версия ПО (2), адрес (2) |
| 0x05 | Read Status Counter | тип энергии (1), 0 = активная прямая; старое поколение — без данных | 30 байт: тип, конфиг, Kн(2), Kт(2), сумма(4), сумма по тарифам(4), T1…T4 (4×4); старое поколение — 26 байт |
| 0x0A | ReadFactoryString | № поля (1): 1 заводской номер, 2 дата, 3 завод, 4–5 наименование | № поля + 30 ASCII |
| 0x10 | ReadConfigure | — | конфигурация, роль, биты реле (новое поколение, 19 байт) |
| 0x1C | ReadDateTime | — | сек, мин, час, день недели, день, месяц, год |
| 0x2B | ReadInstantValue | группа (1), 0 — основная | напряжения, токи, мощности |
| 0x30 | GetInfo | — | ID платы, версия, наработка… |
| 0x3A | OperateOverload (P) | № реле (1), 0 — реле отключения; команда (1): 0 замкнуть, 1 разомкнуть | — |

(P) — нужен пароль. Остальные команды из описания доступны через кнопку «Команда HEX».

## Открытые вопросы

- Сетевой адрес белорусских МИРТЕК-1-BY: посмотреть в MeterTools или вычитать Ping'ом,
  если счётчик отвечает на адрес 0.
- Какой из двух паролей (№0, №1) нужен для 0x3A на BY-прошивке.
- Как USB-радиомодем Миртек оборачивает эти кадры при передаче по радио.
