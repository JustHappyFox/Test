# Обследование: счётчики, интерфейсы, протоколы

Данные с фотографий (РУП «Минскэнерго») и из открытых источников. Производители сайтов
energomera.by, mirtekgroup.com из среды разработки недоступны, поэтому руководства нужно
прислать отдельно.

индексов из каталогов, нужно подтвердить по руководству.

## Что известно о протоколах

**Энергомера CE208BY / CE318BY (Фанипольский завод).**
Оптопорт по IEC 62056-21, скорость 9600. У российских CE208 есть две ветки прошивок:
«IEC» (текстовый протокол ГОСТ IEC 61107-2011, команды вида `ET0PE()`, пароль по умолчанию
`777777`) и «СПОДЭС» (DLMS/COSEM, адрес 16, пароли низкого и высокого уровня). Какая ветка
у белорусских BY, по открытым источникам не определяется — это покажет пробник по ответу
на `/?!`: признак `\2` в идентификации означает DLMS.
Радиоканал 433,05–434,79 МГц, с ПК работает «USB-радиомодуль 2141». Как модуль обменивается
с ПК (прозрачный COM-порт или собственная обёртка), в открытых источниках не описано.
ПО: AdminTools (Энергомера), для BY возможно собственное ПО завода.

**МИРТЕК-1-BY.**
Протокол «МИРТЕК» (фирменный, двоичный), у российских моделей дополнительно СПОДЭС.
Скорость любого интерфейса 9600. Радио 433 МГц, с ПК работает USB-радиомодем Миртек и
ПО «Конфигуратор». Описание протокола «МИРТЕК» производитель выдаёт заказчикам —
Энергосбыту его нужно запросить (или взять из комплекта поставки АСКУЭ).

## Открытые вопросы

1. Какой именно радиомодуль есть у контролёра: Энергомера 2141, Миртек или иной.
   Нужны название в диспетчере устройств Windows и VID/PID.
2. Названия программ на ПК и их документация (руководство пользователя, описание протокола).
3. Руководства по эксплуатации CE208BY S51, CE318BY S31/R32, МИРТЕК-1-BY W9
   (разделы «Протокол обмена», «Управление нагрузкой», «Пароли»).
4. Модель телефона и версия Android (OTG должен поддерживаться).
5. Доступ к стендовому счётчику для проверки команды реле.
