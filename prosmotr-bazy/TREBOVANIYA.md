# Журнал требований: «Поиск абонента»

Программа поиска абонентов по базе FoxPro `O:\BASAFOX\ABONENT.DBF` (около 1 млн записей, 391 МБ) -
ТОЛЬКО ЧТЕНИЕ. Файлы: `prosmotr.ps1` (скрипт со встроенным C#), `zapusk.vbs`, `zapusk.bat`,
`instrukciya.txt`, `selsovety.txt`. Архив для пользователя - `prosmotr-bazy.zip` (корень репозитория).
Исходник C# при разработке - отдельным файлом, в `prosmotr.ps1` вставляется между `$code = @'` и `'@`.

## Постоянные правила проекта
- Базу только читать. Никакой записи в базу.
- Искать прямо в базе по индексам (CDX), как программа базы: данные всегда актуальные.
  НЕ загружать и НЕ кэшировать всю базу (ни в память, ни на диск) - пользователь это прямо запретил.
- Запуск - за секунды: программа собирается один раз после обновления и хранится готовой (dll в профиле).
  Без окна PowerShell, окно программы сразу развёрнуто.
- Поиск по ФИО - через свой индекс `indeks_fio.dat` в папке программы; он дополняется, когда в базе
  появляются/исчезают абоненты (не перестраивается заново каждый раз); его состояние видно в окне.
- Отчёт (`otchet.txt`) - без данных абонентов: только имена таблиц/полей, вид значений, количества.
- Никогда не просить прислать .dbf, индексы, кэши с данными абонентов.
