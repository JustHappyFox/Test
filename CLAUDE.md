# Основные правила

1. Перед любой работой полностью прочитать файл `energosbyt/rules.md`, все строки до конца, и сообщить пользователю, сколько строк в файле и сколько строк прочитано. Число строк в файле узнать командой `wc -l`. Число прочитанных строк — это номер последней прочитанной строки. Если числа не совпадают, дочитать файл и только потом что-либо делать.
