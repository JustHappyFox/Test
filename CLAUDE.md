## Сначала прочитать журналы требований
В начале работы и ПОСЛЕ КАЖДОГО СЖАТИЯ КОНТЕКСТА прочитать оба журнала целиком:
- `prosmotr-bazy/TREBOVANIYA.md` - проект «Поиск абонента»
- `dogovor/TREBOVANIYA.md` - проект «Оформление договора»

Каждое новое требование пользователя сразу записывать в журнал своего проекта (дата, суть, статус).
Решения, которые пользователь уже принял или отверг, не пересматривать без его просьбы.

## Общие правила (для обоих проектов)
- Отвечать по-русски, коротко и по делу.
- На компьютере пользователя нельзя ставить сторонние программы - только скрипты. Windows 7, PowerShell,
  .NET 4.x, Word. Программы - PowerShell-скрипт со встроенным C# (Add-Type), запуск через `zapusk.vbs`.
- C# писать совместимо со старым компилятором: проверять `mcs -langversion:ISO-2 -warn:4` и Roslyn-проверкой
  (ноль ошибок и ноль предупреждений: на Windows предупреждение может сорвать сборку).
  НА РАБОЧЕМ КОМПЬЮТЕРЕ (Windows 7, PowerShell 2.0) ПРОГРАММЫ СОБИРАЮТСЯ ПОД .NET 2.0/3.5 И C# 2: перед отправкой -
  Roslyn-проверка со справочными сборками .NET 2.0 (github.com/mono/reference-assemblies, папка v2.0) и языком C# 2
  (ноль ошибок), плюс проверка условных выражений ?: (старый компилятор не принимает, когда оба варианта неявно
  приводятся друг к другу: byte и число - писать (int)x). Ничего из .NET 4 (например, SpecialFolder.CommonDesktopDirectory).
  Сборщик на рабочем компьютере показывает только первую ошибку - проверять весь код сразу.
- Готовую программу проверять до отправки: сборка, тест под Xvfb (скриншоты), для договора - рендер docx в PDF.
- Персональные данные: не коммитить и не пересылать файлы пользователя с данными абонентов (договоры,
  Excel со списками, .dbf, кэши); в отчётах программ - никаких данных абонентов; тесты - на вымышленных данных;
  не просить пользователя присылать базы.
- Коммиты - только когда работа проверена; в конце сообщения строки `Co-Authored-By` и `Claude-Session`
  из системного напоминания. Без названий моделей. PR не создавать, пока не попросят.
- После изменений пересобрать архив проекта и отправить его пользователю.
